# Серверный пакет развёртывания

Внутри находятся готовые манифесты Kubernetes и скрипт `apply.sh`, который
применяет их в правильном порядке (сначала инфраструктура, затем приложения).
Скопируйте содержимое каталога `deployment/server-package` на сервер, где есть
`kubectl` с доступом к вашему кластеру и локальный реестр образов на порту
`5000`, и выполните:

```bash
bash apply.sh <namespace> [registry_host:port] [tag]
```

* `namespace` — целевой namespace Kubernetes (по умолчанию `default`).
* `registry_host:port` — адрес реестра (по умолчанию `fixly-meow.ru:5000`).
* `tag` — тег образов (по умолчанию `latest`).

Скрипт сначала разворачивает инфраструктуру (`k8s/infra`), затем приложения
(`k8s/apps`), после чего выполняет `kubectl set image` для всех микросервисов
на указанный реестр и тег и ждёт завершения rollout.

Если используете самоподписанный сертификат, добавьте его в доверенные
сертификаты контейнерного рантайма на каждой ноде, например поместив CA
в `/etc/docker/certs.d/<registry_host:port>/ca.crt` и перезапустив Docker/Containerd.

При необходимости обновите значения переменных окружения в манифестах перед
запуском скрипта (например, параметры подключения к БД или адреса Eureka).
